# Marketing Copy — Quick Reference

> Fast lookup for `marketing-specialist`. Full reasoning lives in `concepts/` and `patterns/`.

---

## The 3-Question Gate (apply before approving any copy)

1. **Specific?** — "solves your problem" fails. "Invoicing: 60 days → same month" passes.
2. **True and verifiable?** — no invented or generalized numbers, ever.
3. **Right audience?** — the pain named must be that reader's actual pain, not the category's.

---

## Banned Words / Phrases (agency jargon — cut on sight)

`solução completa` · `líder em` · `revolucionário` · `sinergia` · `disruptivo` · `de ponta` ·
`inovador` (as a standalone claim) · `world-class` · `best-in-class` · `game-changing` ·
`cutting-edge` · `seamless` (overused) · "Saiba mais" as a CTA with no other context

---

## Headline Checklist

- [ ] Names the transformation (before → after), not just the category
- [ ] Contains a concrete noun, not an abstraction ("compliance trapped in paperwork", not "efficiency")
- [ ] Under ~12 words for a hero; case-study headlines can run longer if still concrete
- [ ] Passes read-aloud test — sounds like a person said it, not a deck

---

## Case Study Section Order

```
Kicker (Case Study N — category) → Headline → Subhead → Meta row (client/sector/stack/status)
  → 01/Problem → 02/Approach → 03/Solution → 04/Result → CTA (two options: contact + back)
```

Full detail: `patterns/case-study-structure.md`

---

## CTA Naming Pattern

`{verb} + {specific object}` — never a bare "Learn more" / "Saiba mais".

Good: "See the full case study →" · "Tell me about it →" · "Ver o case completo ↓"
Bad: "Saiba mais" · "Click here" · "Submit"

---

## Social Proof — What Counts

| Counts | Doesn't count |
|--------|----------------|
| A number the founder explicitly confirmed | "Illustrative" numbers dressed as real ones |
| A named, real outcome ("60 days → same month") | Vague superlatives ("much faster") |
| A concrete before/after state | A feature list with no outcome attached |

---

## Per-Page SEO Minimum

- [ ] Unique `<title>` (not copy-pasted from another page)
- [ ] Unique `<meta name="description">` naming the specific product/problem
- [ ] `<h1>` matches the page's actual promise, not a generic template phrase
