# Pattern: CTA Design

> A call-to-action is a promise about what happens next. Vague CTAs create hesitation because the
> reader can't picture the outcome of clicking.

---

## Naming Pattern

```
{verb} + {specific object or outcome}
```

| Context | Good | Bad |
|---------|------|-----|
| Case card → case page | "See case study →" | "Learn more" |
| Case page → contact | "Tell me about it →" | "Contact us" |
| Case page → back to grid | "← All solutions" | "Go back" |
| Newsletter/lead form | "Request Demo →" | "Submit" |

---

## One CTA Per Intent, Not Per Section

A page can have multiple CTAs (e.g. "Tell me about it" and "← All solutions" together at the
bottom), but each represents a genuinely different intent — don't offer three variations of
"contact me" on the same screen; it splits attention without adding a real choice.

---

## Primary vs. Secondary Styling

Reserve the strongest visual treatment (brand color, glow/shadow) for the CTA that represents the
actual conversion goal (usually contact/demo). Navigation-style CTAs ("back to solutions") should
look clearly secondary so the visitor's eye still lands on the primary action first.

---

## Arrow Convention

This site uses a trailing arrow (`→` for forward actions, `↓` for scroll-to-content, `←` for
backward navigation) consistently on CTA text. Keep this convention on every new CTA — a CTA
without the arrow reads as unfinished once the pattern is established elsewhere on the same page.
